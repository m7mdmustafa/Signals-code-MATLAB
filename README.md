
# 🎧 MATLAB Audio Signal Processing

A MATLAB project for analyzing and processing an audio signal in both the time and frequency domains.

## 📌 Project Overview

This project analyzes an audio signal using MATLAB and applies several signal processing techniques, including:

- Time-domain analysis
- Frequency-domain analysis using FFT
- Signal energy calculation
- Parseval's theorem verification
- Peak frequency detection
- Frequency-domain notch filtering
- Signal reconstruction using IFFT
- Exporting filtered audio signals

## 🛠️ Technologies Used

- MATLAB
- Fast Fourier Transform (FFT)
- Inverse Fast Fourier Transform (IFFT)
- Audio Signal Processing
- Frequency-Domain Filtering
